# Nihon Trip

App personal (PWA) para un viaje a Japón que funciona sin conexión. Dirección: https://agallegosns.github.io/App-Japon/

**Estado:** fases 1 (base y Laboratorio) y 2 (interfaz y navegación) hechas. Reservas e itinerario llegan en la fase 3.

Instalar: abre la dirección en Safari → Compartir → «Añadir a pantalla de inicio», y ábrela siempre desde el icono.

Las instrucciones para el desarrollo están en [CLAUDE.md](CLAUDE.md); las tareas en [TASKS.md](TASKS.md).
